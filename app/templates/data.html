What the file needs to look like
  • A header row. Only name is required; column order doesn’t matter.
  • Recognised columns: {{ item_columns|join(', ') }}. Common alternatives like qty, tag, serial and min level are understood too.
  • No kind column? A row with a quantity is treated as a consumable, anything else as a single asset.
  • Rows are matched to what’s already here by asset tag, or by name and category when there is no tag — so re-importing updates rather than duplicates.
  • If anything in the file is wrong, nothing is imported and you’ll get the line numbers.
  • Imports never change who is holding an asset. Use check in / check out for that.

The simplest way to see the format is to export what you have and edit that file.
